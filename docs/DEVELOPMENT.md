# 파자마 캡쳐 — 자세한 설명서·개발 안내

> 처음 쓰는 분은 [저장소 첫 화면(README)](../README.md)을 먼저 보세요. 이 문서는 기능을 하나하나 자세히 적은 설명서이고, 아래쪽에 빌드·파일 구성·시험 방법이 있습니다.

윈도우 캡쳐 도구처럼 화면을 찍고, 창을 찍고, 화면을 GIF·MP4로 녹화하는 프로그램입니다. 설치 없이 `파자마캡쳐.exe` 하나만 있으면 됩니다(윈도우 10·11에 기본으로 들어 있는 .NET Framework 4.x 사용). MP4 녹화만 무료 프로그램 ffmpeg가 추가로 필요합니다.

## 실행
`파자마캡쳐.exe`를 더블클릭합니다. 어디로 옮겨도 동작합니다. 이미 켜져 있으면 새로 뜨지 않고 켜져 있는 창이 앞으로 나옵니다.

## 사용법

### 영역 캡쳐
1. **영역 캡쳐**를 누르면 화면이 어두워집니다(모니터가 여러 대면 모두).
2. 마우스로 끌어서 범위를 정합니다. 창 위에서 **클릭만 하면 그 창 범위**가 잡힙니다.
3. 범위를 정한 뒤에도 조절할 수 있습니다.
   - **크기:** 분홍 테두리의 손잡이 8개를 끕니다.
   - **위치:** 범위 안쪽을 끕니다.
   - **키보드:** 화살표로 1점씩 옮기고, Shift+화살표로 1점씩 크기를 바꿉니다.
   - **다시 고르기:** 범위 바깥을 다시 끌거나, 오른쪽 클릭으로 처음부터 고릅니다.
4. 아래 도구 막대에서 고릅니다.
   - **복사 (Enter):** 클립보드에 복사합니다. 「자동 저장」이 켜져 있으면 PNG로도 저장합니다. 범위 안을 더블클릭해도 같습니다.
   - **저장…:** 위치·이름·형식(PNG·JPG·BMP)을 골라 저장하고, 클립보드에도 복사합니다.
   - **● 녹화:** 그 범위로 바로 녹화를 시작합니다.
   - **취소(Esc):** 아무것도 하지 않고 닫습니다.

### 창 캡쳐
**창 캡쳐**를 누르고 마우스를 창 위에 올리면 그 창이 분홍 테두리로 강조됩니다. 클릭하면 그 창의 테두리 범위 그대로 찍어 클립보드에 복사합니다(자동 저장이 켜져 있으면 PNG로도 저장합니다). 바탕 화면 위에서 클릭하면 그 모니터 전체를 찍습니다.

### 녹화(GIF·MP4)
1. 「녹화 설정」에서 형식(GIF·MP4), 초당 장면 수(10·15·20·30), 마우스 커서 포함 여부를 정합니다.
2. **● 녹화**를 누르고 영역을 끌어서 정하거나 창을 클릭한 뒤 **● 녹화 시작**(Enter)을 누릅니다.
3. 녹화하는 동안 범위 둘레에 분홍 테두리가 깜빡이고, 범위 근처에 녹화 막대(경과 시간·**■ 정지**·**취소**)가 뜹니다. 막대는 끌어서 옮길 수 있습니다.
4. **■ 정지**를 누르면 저장하고 오른쪽 아래에 알림이 뜹니다. 알림을 누르면 파일이 열리고, 「폴더에서 보기」를 누르면 탐색기에서 보여 줍니다. **취소**를 누르면 녹화를 버립니다.

- **찍히지 않는 창:** 테두리·녹화 막대·알림 창은 캡쳐와 녹화에 찍히지 않습니다. 막대가 범위 안에 있어도 결과물에는 나오지 않습니다.
- **녹화 범위:** 녹화를 시작할 때 정한 범위로 고정됩니다. 녹화 중에 창을 옮겨도 범위는 따라가지 않습니다.
- **GIF:** 256색이라 사진·영상처럼 색이 많은 화면은 띠가 생길 수 있습니다. 바뀐 부분만 저장해서 문서·프로그램 화면은 작게 나오지만, 영상이 재생되는 화면은 금방 커집니다(1920×1080 화면에서 영상이 재생되면 5초에 약 30MB). 길거나 큰 녹화는 MP4를 권합니다.

### 녹화 틀(꿀캠 방식) — v1.2.0
녹화할 범위를 **틀 창으로 먼저 띄워 놓고** 자리와 크기를 맞춘 뒤 녹화합니다. 같은 자리를 여러 번 녹화할 때 편합니다. 위의 「● 녹화(끌어서 범위)」 방식도 그대로 쓸 수 있습니다.

1. 메인 창 오른쪽 위 **▣ 녹화 틀**(아래 칸)을 누르면 분홍 틀이 뜹니다. 처음에는 640×360, 다음부터는 지난번 자리·크기로 뜹니다.
2. 틀 안쪽은 비어 있어서 뒤 화면이 그대로 보이고, 클릭도 뒤 창으로 그대로 전달됩니다.
3. 자리와 크기를 맞춥니다.
   - **옮기기:** 위 막대의 빈 곳(왼쪽 점 손잡이 ⠿)을 끕니다. 다른 모니터로 옮겨도 됩니다.
   - **크기:** 테두리 가장자리나 진한 모서리를 끕니다. 막대의 크기 표시(예: `640 × 360`)가 바로 바뀝니다.
   - **정해진 크기:** 크기 표시를 누르면 640×360·854×480·1280×720(HD)·1920×1080(풀HD)·800×600·1080×1080·720×1280과 **직접 입력…**을 고를 수 있습니다.
   - **키보드:** 틀을 한 번 누른 뒤 화살표로 1점씩 옮기고, Shift+화살표로 크기를 바꿉니다.
4. 막대의 **● 녹화**(또는 Enter)를 누르면 틀 안쪽이 녹화됩니다. 형식·초당 장면·커서는 메인 창 「녹화 설정」을 따릅니다.
5. 녹화 중에는 테두리가 빨갛게 깜빡이고 **크기·자리가 잠깁니다**. 막대에 경과 시간과 **■ 정지**·**취소**가 보입니다. 정지는 언제든 누를 수 있습니다. 틀이 앞에 있을 때는 Enter로도 정지합니다.
6. 저장이 끝나도 틀은 남아 있어 같은 자리에서 바로 또 녹화할 수 있습니다. 막대의 **닫기**(또는 Esc)나 메인 창의 **▣ 녹화 틀 닫기**로 닫습니다.

- **찍히지 않음:** 틀의 테두리와 막대는 안쪽 범위 바깥에 있고, 틀 창 전체가 캡쳐·녹화에서 빠집니다. 범위가 화면 위쪽에 붙어 막대 자리가 없으면 막대가 아래로 가고, 아래도 없으면 범위 안쪽 위에 겹쳐 뜨지만 결과물에는 나오지 않습니다.
- **화면 배율·여러 모니터:** 크기는 실제 화면 점(픽셀) 기준입니다. 배율이 100%가 아닌 모니터나 배율이 다른 모니터로 옮겨도 녹화 범위는 틀 안쪽과 1점도 어긋나지 않습니다. 막대 글자와 테두리 두께만 그 모니터 배율에 맞춰 커집니다.
- **MP4는 짝수 크기:** MP4(H.264)는 가로·세로가 짝수여야 해서, 형식이 MP4면 틀 크기가 짝수로만 맞춰집니다(끌 때 끄는 쪽 가장자리를 1점 당김). GIF는 홀수 크기도 그대로 녹화합니다. 「● 녹화(끌어서 범위)」 방식에서 홀수 크기로 MP4를 녹화하면 예전처럼 오른쪽·아래에 검은 줄 1점을 덧대어 짝수로 만듭니다.
- **틀이 떠 있는 동안**에는 영역 캡쳐·창 캡쳐·끌어서 녹화 단추가 잠깁니다. 틀을 닫으면 다시 쓸 수 있습니다.

### 간단 편집(GIF·MP4) — v1.1.0
녹화한 GIF·MP4를 가볍게 고칩니다. 자세한 영상 편집은 별도 프로그램 「파자마컷」에서 하도록 기능을 간단하게 두었습니다.

**여는 방법:** 녹화 알림의 **편집하기**, 메인 창 「간단 편집」의 **최근 녹화**(이번에 마지막으로 녹화한 파일, 없으면 저장 폴더의 가장 최근 GIF·MP4)·**파일 열기…**, 또는 메인 창에 GIF·MP4를 끌어다 놓기.

**GIF 편집 창**(꿀캠 편집 화면처럼 왼쪽 프레임 목록·가운데 미리보기·아래 재생/저장)
| 도구 | 하는 일 |
|---|---|
| 짝수 프레임만 / 홀수 프레임만 | 2·4·6…번째 또는 1·3·5…번째만 남깁니다. 지운 프레임 시간은 바로 앞에 남은 프레임에 더해 **전체 재생 시간은 그대로**입니다. |
| 고른 프레임 삭제 (Delete) | 목록에서 고른 프레임을 지웁니다(모두 지우기는 막음). |
| 프레임 시간… | 고른/전체 프레임을 같은 시간(초)으로 맞추거나 빠르기(%)를 바꿉니다. 최소 0.02초. |
| 캔버스 크기… | 가로·세로를 바꿉니다(비율 유지, 25·50·75%·기준 크기 버튼). |
| 영역 잘라내기 | 미리보기에서 끌어서 고르고 「잘라내기 적용」(Enter). 고른 영역 안을 끌면 옮겨지고, X·Y·너비·높이 칸으로도 넣을 수 있습니다. 잘라내면 캔버스 크기도 잘라낸 크기로 돌아갑니다. |
| 되돌리기 (Ctrl+Z) | 편집을 하나씩 되돌립니다. |
| 재생 (Space) · 다른 이름으로 저장… (Ctrl+S) | 저장은 기본으로 `원래이름_편집.gif` 새 파일. 원본을 고르면 덮어쓰기 전에 한 번 더 묻습니다. |

- 열 때 프레임을 모두 완성된 그림으로 풀어 `%TEMP%\PajamaCaptureEdit\*.raw` 임시 파일에 둡니다(큰 GIF도 메모리를 많이 쓰지 않게). 창을 닫으면 지워집니다.
- 저장은 녹화와 같은 GIF 저장기(`GifEncoder`)를 씁니다. 앞 프레임과 똑같은 프레임은 저장기가 하나로 합치고 그만큼 길게 보여 줍니다.

**MP4 크기 바꾸기 창:** 해상도(가로·세로)만 바꿉니다. 녹화와 같은 ffmpeg·같은 H.264 설정(`libx264 -preset veryfast -crf 20 -pix_fmt yuv420p`)으로 새 파일을 만들고, 가로·세로는 짝수로 맞춥니다. ffmpeg가 없으면 설치 안내를 엽니다.

### 설정
설정은 바꾸는 즉시 `%APPDATA%\PajamaCapture\settings.ini`에 저장됩니다.

| 설정 | 설명 |
|---|---|
| 찍으면 폴더에 PNG로 자동 저장 | 켜면 「복사」와 「창 캡쳐」 때 저장 폴더에도 PNG를 남깁니다. |
| 저장 폴더 | 기본값은 `사진\파자마 캡쳐`입니다. 파일 이름은 `파자마캡쳐_날짜_시각.png/.gif/.mp4`입니다. |

## MP4 녹화에 필요한 ffmpeg
GIF는 프로그램이 직접 만들지만, MP4(H.264)는 무료 프로그램 **ffmpeg**로 만듭니다. 프로그램은 아래 순서로 ffmpeg를 찾고, 찾으면 「MP4 준비됨」이라고 표시합니다.

1. 「직접 지정…」으로 고른 파일
2. `파자마캡쳐.exe`와 같은 폴더의 `ffmpeg.exe` 또는 `ffmpeg\bin\ffmpeg.exe`
3. 시스템 PATH, winget·scoop·chocolatey 설치 위치, `C:\ffmpeg\bin`

### 설치 방법(하나만 하면 됩니다)
- **가장 쉬운 방법:** 프로그램의 **ffmpeg 설치** 버튼을 누릅니다. 명령 창이 열리고 윈도우 기본 설치 도구가 `winget install -e --id Gyan.FFmpeg`를 실행합니다. 설치가 끝나면 그 창을 닫고 파자마 캡쳐 창으로 돌아오면 자동으로 다시 찾습니다.
- **직접 받기:** https://www.gyan.dev/ffmpeg/builds/ 에서 `ffmpeg-release-essentials.zip`을 받아 압축을 풉니다. 그 안의 `bin\ffmpeg.exe`를 `파자마캡쳐.exe` 옆에 복사하거나 **직접 지정…**으로 고릅니다.

ffmpeg가 없을 때 MP4로 녹화하려고 하면 설치 안내를 열지, 이번에는 GIF로 녹화할지 묻습니다.

## 왜 C# WinForms(.NET Framework)인가
- **설치가 필요 없음:** 윈도우 10·11에 기본으로 들어 있는 .NET Framework 4.x와 C# 컴파일러만 씁니다. 결과물은 exe 한 개(약 120KB, 아이콘 포함)입니다. 파이썬+PyQt처럼 수십~수백 MB짜리 실행 파일을 묶을 필요가 없습니다.
- **윈도우 기능을 직접 호출:**
  - 화면 복사는 BitBlt로 합니다.
  - 창 인식은 EnumWindows로 하고, 그림자를 뺀 실제 창 테두리 크기를 DWM에서 가져옵니다.
  - 모니터별 배율은 Per-Monitor V2로 처리합니다.
  - 녹화용 작은 창들은 캡쳐에서 뺍니다(WDA_EXCLUDEFROMCAPTURE).
  - 그래서 모니터 배율이 서로 달라도(예: 125%와 200%) 좌표가 정확합니다.
- **같은 방식의 기존 프로그램:** 같은 폴더의 「파자마네이머」(PajamaNamer)와 만드는 방식·핑크 테마 파일(`src\PinkTheme.cs`)이 같습니다.

## 다시 빌드
`build.cmd`를 실행하면 윈도우 기본 C# 컴파일러로 `파자마캡쳐.exe`를 새로 만듭니다. 아이콘을 바꾸려면 `python make-icon.py`(Pillow 필요)를 실행한 뒤 다시 빌드합니다.

버전은 `src\MainForm.cs`의 `Program.Version` 한곳에서 바꿉니다. 창 오른쪽 위의 「v1.2.0」 표시와 exe 파일 속성(파일 버전·제품 버전)에 함께 쓰이므로, 바꾼 뒤 다시 빌드하면 둘이 어긋나지 않습니다. 화면 시험(`tests\run-tests.cmd`의 [4])이 두 값이 같은지 확인합니다.

| 파일 | 내용 |
|---|---|
| `src\MainForm.cs` | 메인 창·설정·찍기→고르기→저장 흐름 |
| `src\Overlay.cs` | 어둡게 덮은 고르기 화면(끌기·손잡이·창 강조·도구 막대) |
| `src\ScreenGrab.cs` | 화면 복사, 열린 창 목록 |
| `src\Recorder.cs` | 녹화(찍는 일꾼·저장 일꾼), ffmpeg 연결과 찾기 |
| `src\GifEncoder.cs` | GIF 저장기(장면별 256색 팔레트, 바뀐 부분만 저장) |
| `src\Popups.cs` | 녹화 테두리·녹화 막대·알림 창 |
| `src\FrameWindow.cs` | 녹화 틀(꿀캠 방식): 안쪽이 뚫린 틀 창, 끌어서 옮기기·크기, 정해진 크기 메뉴, 녹화 중 잠금 |
| `src\EditCore.cs` | 간단 편집의 속: 프레임 임시 저장소, GIF 프로젝트(솎기·지우기·시간·잘라내기·크기·되돌리기·저장), MP4 크기 바꾸기(ffmpeg) |
| `src\EditorForms.cs` | 간단 편집 화면: GIF 편집 창, MP4 크기 바꾸기 창, 프레임 시간·캔버스 크기 대화 상자 |
| `src\PinkTheme.cs` | 핑크 테마(파자마네이머와 같은 파일) |
| `src\SelfTest.cs` | 시험용 실행 방식(`--selftest`) |

## 시험
`tests\run-tests.cmd`를 실행합니다(먼저 `build.cmd`). 임시 폴더에서만 파일을 만들고 끝나면 지웁니다.

1. **GIF 저장기:** 합성 장면으로 GIF를 만들고 원본과 색·장면 수·시간을 비교합니다(Python·Pillow·NumPy 필요).
2. **GIF 녹화:** 실제 화면을 3초 녹화합니다.
3. **MP4 경로:** 가짜 ffmpeg(`tests\FakeFfmpeg.cs`)로 형식·크기·장면 수가 올바르게 넘어가는지 봅니다.
   - **간단 편집 GIF:** 솎기·지우기·시간·잘라내기·크기를 차례로 해 보고 저장한 GIF를 `tests\check_edit.py`(Pillow)로 풀어 크기·프레임 수·시간·그림을 비교합니다. 편집 창을 화면 밖에 띄워 버튼 처리도 확인합니다.
   - **간단 편집 MP4:** 진짜 ffmpeg가 있으면 시험 영상을 만들어 크기를 절반으로 바꾸고 결과 크기·길이를 확인합니다(없으면 건너뜀).
   - **녹화 틀:** 틀 창을 띄워 창이 안쪽 범위 바깥에 정확히 붙는지, MP4일 때 짝수 맞춤, 녹화 중 잠금, 배율이 다른 모니터에서의 크기를 봅니다. 진짜 ffmpeg가 있으면 홀수 크기를 넣은 틀로 MP4를 녹화해 결과 크기를 확인합니다.
4. **실제 앱 화면:** 앱을 띄워 **진짜 마우스·키보드 입력**으로 영역 캡쳐·창 캡쳐·녹화·녹화 틀을 하고 결과 파일과 클립보드를 확인합니다. 녹화 틀은 끌어서 크기·자리를 바꾼 뒤, 틀 안쪽에 맞춘 시험 무늬(바깥 1점 빨강)를 녹화해 결과 가장자리가 모두 빨강인지 봅니다. 배율이 다른 모니터가 있으면 틀을 그리로 끌어 옮겨 한 번 더 합니다. 40초쯤 마우스가 저절로 움직이니 그동안 마우스를 만지지 마세요.
   - 시험은 설정 위치를 임시 폴더로 돌려 실행하므로, 평소 쓰는 파자마캡쳐가 켜져 있어도 따로 돕니다.
